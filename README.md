# 샤인부동산 동작구 아파트 브리핑

동별 단지와 입지를 살펴보는 공개 시연판입니다. 거래금액, 거래량과 추천매물의 샘플은 예시입니다.

지도 및 일부 상권 자료의 출처는 [OpenStreetMap 기여자](https://www.openstreetmap.org/copyright)이며 [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/)을 따릅니다. 지도는 [BBBike 서울 자료](https://download.bbbike.org/osm/bbbike/Seoul/)에서 추출했습니다. 가공한 지도와 상권 자료는 index.html의 mapTiles 및 osmPlaces 데이터에 포함되어 있습니다.
